# FILTECH Website

O FILTECH Website é um projeto de front-end desenvolvido para apresentar a empresa FILTECH, especializada em soluções de segurança eletrónica.

## Tecnologias

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Funcionalidades

- Página Inicial
- Sobre a Empresa
- Serviços
- Produtos
- Galeria
- Contactos
- Design Responsivo
- Interface Moderna

## Objetivo

Criar uma interface profissional para apresentação ao cliente, preparada para futuramente integrar um sistema completo de gestão, autenticação, loja online e painel administrativo.
